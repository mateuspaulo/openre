| Version | Supported |

---

## 2. Reporting a Vulnerability

The OpenRe team takes the security and privacy of user data with the highest priority. If you discover a vulnerability, especially regarding:
- Accidental write operations to source media.
- Path traversal vulnerabilities during file recovery.
- Memory corruption or untrusted preview execution vulnerabilities.
- Accidental network socket creation.

**Please report it responsibly:**
- Open a GitHub Security Advisory on our repository or email `security@openre.org`.
- Provide reproduction steps and synthetic test cases.
- Do NOT post exploit details or sensitive disk dumps in public issue threads.

We will acknowledge receipt within 48 hours and work with you to patch and publish an advisory.
